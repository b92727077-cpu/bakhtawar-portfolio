01 / THE IDEA

A clearer place
to study.

The starting point was simple: create a personal study space where a student can reach subject content and useful learning tools without jumping between unrelated pages.

The project is intentionally treated as a developing prototype. Its purpose is both practical and educational: to organise a useful interface while learning how separate pages and browser-side code fit together.

02 / WHAT'S IN THE REPOSITORY

A multi-page
structure.

The public repository contains a landing page, a dashboard file, subject and chapter pages, an extra-learning page, flashcard files and a timer page. The dashboard markup includes navigation for subjects, study planning, notes, extra learning, revision, focus timing, study analysis, settings and backup.

03 / TECHNICAL NOTES

What the code
shows.

HTML

Page structure

Separate HTML files are used for the entry page, dashboard, subject content and study tools.

CSS

Visual presentation

The entry page defines its own styling, and the dashboard references a shared stylesheet.

JavaScript

Browser-side behaviour

The entry page stores the entered student name in localStorage and routes the visitor to the dashboard. The dashboard source also references an application script.

DEPLOY

Public publishing

The project is hosted through GitHub Pages, making the prototype accessible through a public URL.

04 / LEARNING & NEXT STEPS

Build, test,
then refine.

Working on this project creates practice in connecting pages, organising a growing codebase, using browser storage and publishing updates. The next stage is systematic testing: checking every navigation path, confirming which tools work as intended, improving mobile layouts and documenting limitations clearly.
